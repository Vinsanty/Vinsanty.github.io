# Ribotech — сайт хакатона

Проект для хакатона Ribotech. Сайт разработан по макету организаторов (Figma) с добавлением геолокации и поиска компаний.

## Стек
- JavaScript
- React
- Redux

## Возможности
- Вёрстка по макету из Figma
- Определение города, широты и долготы пользователя
- Поиск компаний


## Структура
- **Главная** — лендинг по макету организаторов
- **Геолокация** — определение местоположения пользователя
- **Поиск компаний** — поиск по базе компаний-участников
